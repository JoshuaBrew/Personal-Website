# Joshua Brewington — Personal Portfolio Website

A clean, responsive static website showcasing my professional experience as a Data Analyst, technical skill set, cloud/database background, and portfolio projects in Machine Learning, Python, and Data Analytics.

---

## 🌐 Live Preview & Features

This website serves as a central hub for my professional work, featuring a modern, multi-section single-page layout with interactive navigation:

* **Hero / Biography Section:** An introduction to my background, education at James Madison University (BS in Integrated Science and Technology), and core technical interests in AI and Machine Learning.
* **Skills & Professional Experience:** A detailed breakdown of my experience as a Junior Data Analyst Contractor for Claxton Logistics supporting the United States Naval Community College, alongside categorized technical skill sets (Python, SQL, AWS, Tableau, Power BI, Web Development).
* **Featured Projects Showcase:** Visual project cards linking directly to standalone GitHub repositories for my ML models, Python applications, and statistical analyses.
* **Resume Access:** Direct download link for my latest resume file (`Brewington-Resume.pdf`).
* **Contact & Links:** Integrated communication links for email, LinkedIn, and GitHub.

---

## 💻 Tech Stack & Architecture

* **Frontend:** HTML5, CSS3 (`style.css`)
* **Assets:** Custom image assets (`scooter.jpg`, `AI.png`, `Black-Jack.png`, `NBA.png`) and downloadable PDF document (`Brewington-Resume.pdf`)
* **Deployment:** GitHub Pages (Static Hosting)
